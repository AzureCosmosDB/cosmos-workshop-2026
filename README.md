# Lab Content for Cosmos DB Workshop

Each lab contains the same folder structure for both languages and before and after versions:

```
<lab>/
├── before/              Starting point with missing code sections to fill in
│   ├── csharp/
│   └── python/
├── after/               Completed solution as reference
│   ├── csharp/
│   └── python/
```

Lab 4B is online in Fabric so has no local code component.
